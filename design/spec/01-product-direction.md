# 01 · Продукт, референсы и направление

## 1. Продукт

**«Волна»** (рабочее название) — файловый менеджер для Linux-десктопа: плотный, «технический» инструмент для ежедневной работы с файлами и каталогами. Целевой пользователь — разработчик/инженер, который ценит скорость, клавиатуру, плотность и предсказуемость, но не хочет жить в IDE.

Ключевые задачи интерфейса:

1. Быстро понять, **что лежит в папке** и когда это менялось.
2. Быстро **перейти** в другое место (путь, табы, дерево, закладки).
3. Настроить **представление** под задачу: значки / столбцы / подробности, группировка, сортировка, масштаб.
4. Оставаться спокойным и сфокусированным: никаких декоративных эффектов, только данные и состояние.

Платформа: desktop Linux, тёмная тема по умолчанию, русская локаль. Язык интерфейса — русский, технические значения (размеры/даты/проценты) — моноширинным шрифтом.

## 2. Референсы

### 2.1 KDE Dolphin (главный референс контента)

Пользователь указал конкретный экран из `reference/` — Dolphin, тёмная Breeze-тема, вид **«Столбцы»** с группировкой по дате изменения, в двух состояниях (с группировкой `183441`, сортировка по размеру без группировки `183407`) и диалог «Режим просмотра» (`183418`). Что берём:

- контентную модель: папки, размер, дата, дерево мест, устройства;
- «Столбцы» как сигнатурный вид: крупные папки + 3 строки (имя/размер/дата), колонки по группам дат;
- курс на плотность и «файловый менеджер, а не веб-приложение»;
- путь, свободное место, статус — как часть рабочего экрана.

Измеренная спека: [`design/reference/dolphin-spec.md`](../reference/dolphin-spec.md) (398 строк).

### 2.2 JetBrains New UI (главный референс языка панелей)

PyCharm/IntelliJ IDEA 2023–2025 New UI: 40px ритм хрома, непрерывная полоса заголовков tool window + табы, вертикальные рейлы, инспектор, нижняя панель, 28px статус-бар, 24px строки, плоская двухтоновая тёмная тема, акцент только как состояние. Что берём:

- панельную грамматику и ритм;
- токены (`#1e1f22`/`#2b2d30`/`#393b40`/`#3574f0`);
- подход к настройкам отображения (поповер, а не отдельное окно);
- светлую тему как референс для будущего (в B реализована).

Измеренная спека: [`design/reference/jetbrains-spec.md`](../reference/jetbrains-spec.md) (474 строки).

### 2.3 Как референсы соединяются

| Слой | Источник | Правило |
|---|---|---|
| Хром, панели, рейлы, табы, инспектор, статус-бар | JetBrains | 40px ритм, две поверхности, 1px линии, плоские панели, без градиентов/теней внутри окна |
| Контент и его отображение | Dolphin | «Столбцы» с 3-строчными ячейками и группами дат; «Значки» и «Подробности» — как альтернативные режимы того же контента |
| Плотность | оба | строки 24px, дерево 24px, тулбар 40px, никаких «воздушных» отступов |
| Токены | JetBrains | C использует тёмную палитру New UI; light-палитра описана как референс (B) |
| Акценты | JetBrains | `#3574f0` только как состояние (фокус, активная вкладка, прогресс); папки — синий контент, не акцент |

## 3. Выбранное направление

Из трёх вариантов выбрано **C — Dolphin × JetBrains**:

- **A — Dolphin Breeze** — эталон верности референсу; оставлен как справочник и «консервативный» сценарий. Не выбран как основной: мало собственного лица, слабо масштабируется на профессиональный инструмент.
- **B — JetBrains Workbench** — эталон панельной грамматики и light-темы; оставлен как источник паттернов для панелей, поповеров и тем. Не выбран как основной: теряет сигнатурный вид «Столбцы» и перегружен IDE-метафорами.
- **C** — соединяет контент/характер Dolphin с дисциплиной JetBrains: все три режима просмотра, группировка, настройки отображения в поповере «Вид», плотный и спокойный хром. Это рекомендуемое направление.

## 4. Принципы дизайна

1. **Две поверхности и линии.** Глубина — только тоном (`#1e1f22` / `#2b2d30`) и 1px линиями; внутри окна нет градиентов, теней и стекла.
2. **40/24 ритм.** Хром 40px, строки данных 24px, вкладки 40px, статус-бар 28px. Исключение — крупные ячейки «Столбцов» (62px), это фирменный контент.
3. **Один контрол — одна функция.** Дубли нельзя: одна настройка, одна тема, один поиск/фильтр, один «Вид», один терминал (в текущей версии терминала нет вовсе).
4. **Путь только сверху.** Адрес — в тулбаре; в статус-баре его нет. Кнопка «Вид» закреплена слева от пути, чтобы не «прыгать» при изменении длины пути.
5. **Настройки отображения — в поповере «Вид».** Режим, группировка, сортировка, масштаб, скрытые файлы и плотность. Не отдельное модальное окно и не набор кнопок по интерфейсу.
6. **Все режимы настоящие.** «Значки», «Столбцы», «Подробности» — три реальных представления одних данных, а не заглушки; группировка работает во всех.
7. **Статус-бар — про состояние.** Слева статус («Сканирование…»/«Готово.»), справа свободное место + устройство (`sdc1`). Счётчики — в тулбаре редактора.
8. **Плотность как норма.** 24px строки, компактный режим (20px/54px/12px) для ноутбуков; никаких больших отступов «для дыхания».
9. **Акцент — состояние.** Синий только для фокуса, активной вкладки, выбранного действия и прогресса; не для украшения.
10. **Клавиатура и доступность.** Focus-visible, Esc закрывает поповеры/редактирование, роли и aria-атрибуты, live-регион статуса.
11. **Честный прототип.** Данные демонстрационные, но правдоподобные; никакого lorem ipsum и выдуманных метрик.
12. **Тёмная тема первична.** C — тёмная; light описан как референс (B) для будущей реализации.

## 5. Scope

Входит в спеку:

- главное окно и все его зоны (тулбар, хедер-бэнд, рейлы, дерево, редактор с тремя режимами, инспектор, нижняя панель, статус-бар);
- поповер «Вид» со всеми настройками отображения;
- пресеты отображения: выбор, сохранение, перезапись и хранение пользовательских пресетов;
- поведение навигации по путям/табам/дереву;
- состояния (hover/active/selected/focus/disabled/empty/scanning);
- контент-структура (папка `.cache`, 5 групп дат, 2 вкладки-соседа, устройства);
- правила адаптации к будущему продукту (токены, паттерны).

Не входит:

- настоящий файловый ввод-вывод, операции копирования/удаления, права доступа;
- настройки приложения, темы, плагины, горячие клавиши продукта за пределами описанных;
- мобильная/планшетная адаптация (desktop-only);
- light-тема в C (есть только референс-описание из B);
- терминал (удалён по решению пользователя, см. [07-decisions.md](07-decisions.md)).

## 6. Критерии успеха

- Пользователь за 5 секунд понимает, где путь, где представление, где настройки вида и где статус.
- Переключение режима/группировки/сортировки/масштаба не ломает компоновку и не требует перезагрузки.
- Ни один контрол не дублируется; в интерфейсе нет терминала.
- Все состояния читаемы на тёмном фоне при 100% масштабе; текст ≥ 4.5:1 для основного, ≥ 3:1 для второстепенного.
- Макет проходит чек-лист [08-acceptance.md](08-acceptance.md) по всем трём режимам.
