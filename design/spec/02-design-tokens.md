# 02 · Дизайн-токены

Канонический источник — CSS-переменные `:root` в [`design/artifacts/variant-c.html`](../artifacts/variant-c.html). Машинно-читаемая версия — [`tokens.json`](tokens.json). Ниже — роли, значения и правила применения.

## 1. Тёмная тема (C, боевая)

### 1.1 Поверхности и линии

| Токен | HEX | Роль |
|---|---|---|

### 1.2 Текст и иконки

| Токен | HEX | Роль |
|---|---|---|
| `--text-primary` | `#dfe1e5` | основной текст: имена, заголовки, значения |
| `--text-secondary` | `#9da0a8` | вторичный текст, подписи, неактивные вкладки |
| `--text-muted` | `#6f737a` | служебные подписи, meta, placeholder, footer поповера |
| `--icon-primary` | `#ced0d6` | иконки действий (16/20px) |
| `--icon-secondary` | `#6f737a` | второстепенные иконки, шевроны, disabled-иконки |

Правило: заголовки, имена и значения — primary; второй уровень (размер/дата/подписи) — secondary; третий (счётчики, подсказки, footer) — muted. Инверсный текст на акцентной заливке — `#ffffff`.

### 1.3 Акценты и семантика

| Токен | HEX | Роль |
|---|---|---|
| `--accent` | `#3574f0` | фокус-ринг, активная вкладка (3px подчёркивание), активный прогресс, зуммер, radio/checkbox |
| `--accent-soft` | `#25324d` | мягкая акцентная заливка (зарезервировано; в C почти не используется) |
| `--folder-blue` | `#4a88d8` | тело папки (контент, не акцент) |
| `--folder-blue-light` | `#7fb2ec` | верхняя часть/блик папки |
| `--error` | `#db5c5c` | ошибки, заполненность устройств |
| `--warning` | `#f2c55c` | предупреждения |
| `--success` | `#57965c` | успех (готовые операции) |

### 1.4 Иерархия применения

1. `#1e1f22` — «глубокая» поверхность контента (редактор).
2. `#2b2d30` — «хром» вокруг контента (панели/тулбар).
3. `#26282d` — вставленные блоки/поля на хроме или контенте.
4. Разделения — `#393b40` и «зазорный» `#1e1f22`; никаких теней внутри окна.
5. Акцент — только состояние, не декор; папки — синий контент.

## 4. Типографика

| Стиль | Размер/высота | Вес | Семейство | Где |
|---|---|---|---|---|
| UI default | 13px / 1 | 400 | `--ui` (Inter, JetBrains Sans, system-ui) | имена, вкладки, кнопки, попапы, дерево |
| UI secondary | 12px / 1–1.3 | 400 | `--ui` | подписи панелей, статус-бар, meta |
| UI caption | 11px / 1.2 | 400 | `--ui` | footer поповера, placeholder, подписи секций/счётчики |
| Section title | 11px / 1.2 | 600 | `--ui` | заголовки секций «Вид» (`letter-spacing:.02em`, title case) |
| Popover header | 13px / 1.2 | 600 | `--ui` | заголовок «Вид» |
| Panel/tool window title | 13px / 1 | 600 | `--ui` | «Места», «Сведения» |
| Item name (cols) | 12.5px / 1.25 | 400 | `--ui` | имя в 3-строчной ячейке |
| Details row | 12.5px / 1 | 400 | `--ui` | таблица «Подробности» (compact: 12px) |
| Icon tile name | 12.5px / 1.3 | 400 | `--ui` | «Значки», до 2 строк, `line-clamp:2` |
| Mono | 12px / 1–1.3 | 400 | `--mono` (JetBrains Mono, ui-monospace) | размеры, даты, проценты, путь, device, счётчики |
| Dialog/card title | 16px / 1.3 | 600 | `--ui` | имя в инспекторе |

Правила:

- Никаких uppercase-заголовков; title case (`Режим просмотра`, `Группировка`).
- Один шрифт интерфейса на всё; mono только для чисел/технических значений.
- Не загружать внешние шрифты; использовать системный стек, веб-шрифты запрещены (self-contained артефакт).
- Межстрочный интерфейс — 1 (плотно), многострочный текст/описания — 1.3–1.4.

## 6. Иконки и графика

- Сетка 16×16 для действий/строк, 20×20 для рейлов, 14×14 для radio/checkbox-индикаторов.
- Стиль: контурные, скруглённые окончания, штрих 1.25–1.5px, `currentColor`.
- Папки: цветная двухтоновая графика (`--folder-blue`/`--folder-blue-light` + затемнение контура), размеры: 16px (строки/дерево), 40px (компактные колонки), 48px (обычные колонки), 48–72px (плитки «Значки»), 64px (карточка инспектора). Папка — единственный насыщенный цветной глиф; состояние иконок не перекрашивается под контент.
- Все иконки — inline SVG (`<symbol>` + `<use>`), без внешних спрайтов и иконочных шрифтов.
- Статусные индикаторы (ошибка/успех) — точка/полоска, а не перекраска глифа.

## 7. Тени и глубина

Внутри окна теней нет. Тени допустимы только:

| Объект | Тень |
|---|---|
| Окно на «сцене» | `0 30px 90px rgba(0,0,0,.62), 0 6px 18px rgba(0,0,0,.45)` + внутренний контур `inset 0 0 0 1px #3b3e43` |
| Поповеры/меню | `0 12px 32px rgba(0,0,0,.5)` (view-pop) / `0 8px 24px rgba(0,0,0,.45)` (меню) |
| Карточка «приложение закрыто» | `0 24px 70px rgba(0,0,0,.55)` |

## 8. Движение

| Свойство | Значение |
|---|---|
| Переходы состояний | `background-color 120ms ease`, `color 120ms ease`, `border-color 120ms ease` |
| Появление поповера | без анимации размера; мгновенно (или opacity ≤120ms) |
| Скролл/зум | мгновенно, без инерции (это данные, не декор) |
| Reduced motion | при `prefers-reduced-motion: reduce` отключить все transition (кроме мгновенного изменения цвета) |

Никаких hover-подъёмов, parallax, анимации панелей.
