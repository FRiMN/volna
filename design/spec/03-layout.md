# 03 · Анатомия окна и компоновка

Канон: [`design/artifacts/variant-c.html`](../artifacts/variant-c.html). Все размеры — CSS px; компактное окно фиксировано 1440×900 и масштабируется целиком под вьюпорт.

> Метрики ниже — **база 100 % (компактная сетка)**. Масштаб следует за системным UI-кеглем: на 100 %-десктопе это окно 1440×900, на 125 % — ×1.25 (1800×1125), см. [02 · §10](02-design-tokens.md#10-размеры-интерфейса-масштаб-следует-за-рабочим-столом); структура при этом не меняется.

## 1. Сцена и масштаб

- «Сцена»: окно по центру тёмного фона с радиальным градиентом и виньеткой; окно 1440×900, радиус 8px, внешняя тень, внутренний контур 1px `#3b3e43`.
- Масштаб: `scale = min(1, (vw − 48) / (1440 × k), (vh − 48) / (900 × k))`, минимум 0.2; в «развёрнутом» состоянии — `min((vw − 16)/(1440 × k), (vh − 16)/(900 × k))`, где `k` — множитель масштаба интерфейса (1 на 100 %-десктопе, 1.25 на 125 %, см. [02 · §10](02-design-tokens.md#10-размеры-интерфейса-масштаб-следует-за-рабочим-столом)).
- Никакого внутреннего скролла страницы; скролл только внутри областей.

- Нижняя панель — 1360 (между рейлами); рейлы идут на всю высоту app body (830) рядом с ней.
- Статус-бар — на всю ширину окна, поверх рейлов (под ними заканчиваются рейлы).

## 4. Тулбар: порядок и фиксированные позиции

Слева → направо:

```
[☰ 40]  [‹ 24][› 24][↑ 24]  │  [◫ Вид ⌄ 28h]  │  [📁 путь ………………………………][✎][⌄]  …spacer…  [⚙ 24] │ [— □ ✕]
```

1. Меню ☰ — 40×40 (lg-кнопка), hover `#393b40`.
2. Навигация: назад/вперёд/вверх — 24×24, disabled-состояние `#6f737a`.
3. Separator 1×20.
4. **«Вид»** — виджет 28px высотой (иконка + «Вид» + шеврон). Стоит **слева от пути**, позиция фиксирована, чтобы не «прыгать» при разной длине пути.
5. **Путь** — гибкий виджет (`flex:1 1 auto`, min-width 0): иконка папки, текст пути (truncate), шеврон dropdown. Справа от него — кнопка-карандаш 24×24 «Изменить путь» (открывает inline input 24px, mono, select-all). При редактировании виджет пути и карандаш скрыты, показывается input.
6. Spacer (flex) — не даёт правой группе «плавать».
7. Настройки ⚙ 24×24 (поповер сброса).
8. Separator 1×20.
9. Контролы окна: свернуть / развернуть / закрыть — 40×40, close-hover `#db5c5c`; никаких «светофоров» macOS.

Правило: путь — только здесь. В статус-баре пути нет.

## 6. Workspace: левая панель

- Панельный тулбар 32px: поле поиска 24×flex (иконка, placeholder «Поиск…»), кнопки фильтра/сортировки 24×24.
- Дерево: строки 24px (`p-row`), отступ 16px на уровень, twisty 16px, иконка 16px, label 14px, вторичный mono 12px (даты/размеры у «Недавно изменённые»), usage-bar 3px для устройств.
- Секции: «Домашняя папка» (дерево), `.cache`/«Корзина» строки, «В сети», «Недавно изменённые», «Устройства». Дубли строк запрещены.
- Скролл — вертикальный, 8px overlay.

- Заметка `bandNote` — снизу полосы, 13px secondary на chrome-плашке, авто-скрытие ~2.6с (используется для «Путь недоступен» и подсказок).

## 8. Правая панель «Сведения»

- Тело: карточка объекта (иконка 64, имя 17/600, тип 13 secondary) + метаданные (строки 24px, label 12px secondary, value 14px primary/mono) + секции «Доступ» и «Содержимое» (заголовки 13px/600 secondary).
- Путь в метаданных переносится, mono 13.
- Внизу — фиксированные действия: «Открыть» (primary, 32px, accent) и «Показать в папке» (ghost, 32px, border `#393b40`), паддинг 12.
- При выборе файла — тип «Файл», права `-rw-r--r--`; папки — «Папка», `drwxr-xr-x`. При отсутствии выбора — empty state.

## 9. Bottom window

- Шапка 40: табы «Операции» (active, underline 3px) / «Журнал»; справа «—» (свернуть) и «…» (очистить завершённые).
- Контент 140: операции — 4 строки по 24px: иконка 16, имя 14, прогресс 4px, %, скорость, статус; журнал — mono 13 строки с временем.
- Сворачивание: 180 → 40, контент скрыт, шапка остаётся.

## 10. Status bar

- Высота 28, фон chrome, паддинг 8.
- Слева: **только статус** — `Сканирование…` (muted) / `Готово.` (secondary), 13px, `role=status`, `aria-live=polite`.
- Справа: иконка диска 14 + «свободно 22,8 ГиБ» + разделитель «·» + **`sdc1`** (mono 13). Никаких путей, счётчиков, зума и режима просмотра.

## 11. Поповер «Вид»

- Триггер: кнопка «Вид» в тулбаре (слева от пути).
- Размер: ширина 320, `max-height: 820px`, внутренний скролл 8px, паддинг 12, радиус 8, фон `#2b2d30`, border `#393b40`, тень `0 2px 4px rgba(0,0,0,.45)` (в GTK размытие тени становится полями поверхности поповера; тень не должна доходить до триггера — иначе поверхность перехватывает клики по кнопке).
- Позиция: `top: calc(100% + 4px); left: 0` относительно триггера; z-index 60. В GTK левое выравнивание даёт `popover.set_halign(START)`, зазор 4 px — постоянный `offset`; геометрия задаётся до показа и не меняется, иначе открытая панель прыгает (мигание).
- Секции (сверху вниз): «Вид» (заголовок 14/600) → **«Пресеты»** (поле выбора + кнопка сохранения) → «Режим просмотра» → «Группировка» → «Сортировка» (+ сегмент направления) → «Параметры» → «Масштаб» → footer. Секции разделены 1px `#393b40`.
- Строка 26px, radio/checkbox 14px, hover `#393b40`; сегмент направления: контейнер `#1e1f22` + border, активная кнопка `#393b40`; зум-слайдер 96px, трек 4px, thumb 10px accent, проценты mono 13.
- Закрытие: клик вне, Esc, повторный клик по триггеру; `aria-expanded` синхронизирован.
- Пресеты: поле выбора 28px (имя + chevron), кнопка сохранения 28×28; инлайн-список строк 26px с галочкой и внутренним скроллом (max-height ~174px, 6 строк). У кастомных пресетов справа — действия 22×22 (переименовать/удалить), появляются на hover/фокусе.

## 11.1 Диалог «Сохранить пресет»

- Оверлей на всё окно: `position:absolute; inset:0; z-index:70; rgba(0,0,0,.45)`; приложение под ним не интерактивно.
- Карточка 380px по центру, фон `#2b2d30`, 1px `#393b40`, radius 8, padding 16, тень `0 24px 70px rgba(0,0,0,.55)`.
- Состав: заголовок «Сохранить пресет» (14/600) → label «Название пресета» (12/600) → input 28px → подпись «Или выберите существующий» → список существующих (24px) → подсказка (12px muted/warning) → кнопки 32px справа.
- Высота карточки ~300–360px в зависимости от числа пресетов (список скроллится при переполнении).

## 11.2 Диалог «Удалить пресет?»

- Оверлей на всё окно: `position:absolute; inset:0; z-index:75; rgba(0,0,0,.45)`.
- Карточка 380px по центру, те же токены, что у диалога сохранения.
- Состав: заголовок «Удалить пресет?» (14/600), текст «Пресет «<name>» будет удалён. Это действие нельзя отменить.» (14/1.5 secondary), кнопки 32px справа: «Отмена» (ghost) и «Удалить» (filled `#db5c5c`, white).
- Фокус по умолчанию — «Отмена»; Esc/backdrop/«Отмена» закрывают; Enter на «Удалить» подтверждает.

## 13. Адаптация

- Окно не реflow-ится: при уменьшении вьюпорта уменьшается только масштаб. Внутренние размеры панелей/строк фиксированы.
- При реализации в реальном приложении: сохранить вертикальный ритм 40/24/28; при ресайзе окна менять ширину редактора (панели — минимум 200px), не высоты полос.
- Компактная плотность — токен-набор (см. [02-design-tokens.md](02-design-tokens.md#9-плотности)), а не второй макет.
