# 05 · Поведение и состояния

Спека поведения канонического макета C. Все значения и тайминги — из `design/artifacts/variant-c.html`.

## 1. Модель состояния

| Поле | Значения | По умолчанию | Влияние |

## 2. Открытие/закрытие «Вид»

- Клик по `#btnView` — открыть; повторный клик — закрыть.
- Клик вне поповера/триггера — закрыть; `Escape` — закрыть.
- `aria-expanded` на `#btnView` синхронизируется; поповер — не модальный, контент под ним не блокируется.
- Все строки внутри применяются **сразу**: radio/checkbox/сегмент/слайдер; поповер не закрывается при изменении (кроме пунктов настроек).
- Deep-link `#view` открывает поповер при загрузке/`hashchange`.

## 3. Режимы просмотра

Переключение `data-mode` → `state.viewMode`, `syncViewPopover()`, `renderBand()`.

| Режим | Grouped | Ungrouped |
|---|---|---|
| Значки | секции по датам + grid-плитки | один grid без секций |
| Столбцы | 5 колонок с заголовками и сворачиванием | безголовые колонки по 6 строк, горизонтальный скролл |
| Подробности | sticky-шапка + групповые строки + строки 24px | sticky-шапка + плоские строки без групп |

Правила:

- Выбор режима не сбрасывает фильтр/сортировку/группировку/зум/выделение.
- Свёрнутые группы (`collapsed`) актуальны только для «Столбцов» с группировкой; при других режимах игнорируются, но сохраняются.
- Прокрутка полосы сбрасывается на начало при смене режима.
- Один представление = один класс на `.band`: `is-icons` / `is-details` / `is-ungrouped`.

## 4. Группировка

- `Группировка → По дате изменения`: данные разбиваются на 5 групп (`Сегодня`, `Вчера`, `Среда`, `Вторник`, `Неделю назад`), количество объектов в группе показывается в заголовке/колонке.
- `Группировка → По размеру`: полосы `Папки / 0 Б / до 10 КиБ / 10–100 КиБ / 100 КиБ–1 МиБ / 1–10 МиБ / 10–100 МиБ / 100 МиБ–1 ГиБ / больше 1 ГиБ / Без размера`; папки всегда отдельной группой (их `st_size` — размер inode, а не содержимого), файлы без размера — в конце; пороги — таблица `SizeGrouping.BANDS` в `display/grouping.py` (design/grouping.md V5).
- `Без группировки`: элементы объединяются в один список; сортировка применяется глобально; «Столбцы» — безголовые колонки по 6 строк.
- Переключение группировки не меняет набор данных и выделение (если выделенный объект не скрыт фильтром/скрытостью).

## 5. Сортировка

- Ключи: `Дата изменения` (по полю `t`, ISO-like строка YYYYMMDDhhmm), `Размер` (парсинг «16,6 ГиБ» → байты; `null`/«—» всегда в конце), `Имя` (`localeCompare('ru')`).
- Направление: `По убыванию` (по умолчанию) / `По возрастанию`.
- В группированном режиме сортировка действует **внутри** каждой группы; в безгрупповом — по всему списку.
- Стабильность: при равенстве ключей — по имени.
- Переключение сортировки запускает индикацию «Сканирование…» (~650–700 ms).

## 6. Масштаб

- Диапазон 0–100, по умолчанию 50 (100%).
- Формулы (из `applyZoom`):
  - ширина колонки: `s ≤ 50 ? 200 + s*0.72 : 236 + (s−50)*0.88` px (200–280);
  - иконка колонки: `ceil(40 + s*0.16)` px (40–56);
  - иконка плитки: `round(48 + s*0.24)` px (48–72);
  - подпись: `round(85 + s*0.3)` % (85–115%).
- Влияние: «Столбцы» — ширина колонки/размер иконки; «Значки» — размер иконки плитки (ширина плитки подстраивается); «Подробности» — без изменения (строки 24px, иконки 16px — стандарт JetBrains).
- Слайдер в поповере «Вид» (`#viewZoom`); Home/End — 0/100; «Сбросить масштаб» в настройках — 50 (100%).
- Значение отображается в процентах (mono 13) и обновляется мгновенно.

## 7. Показ скрытых файлов

- On: к группе «Сегодня» добавляется `.gitignore` (184 Б, «Сегодня в 14:58»), к «Вчера» — `.cache.lock` (0 Б, «Вчера в 16:40»), оба с приглушёнными иконкой/текстом.
- Off: элементы удаляются; если выбран скрытый объект — выделение переходит на `defaultSel`.
- Работает во всех режимах и при любой группировке.

## 8. Плотная раскладка

- Добавляет класс `is-compact` на окно (`#appWindow`).
- Метрики: колонка 54px (padding 2 8, иконка 40), плитка min-height 132, «Подробности» — 13px; см. [02 · Плотности](02-design-tokens.md#9-плотности).
- Не меняет ширины панелей, высоты полос, положение элементов; выравнивание колонок/строк сохраняется.
- Состояние не сбрасывается при смене режима/вкладки.
- Плотная раскладка — не то же самое, что пресет размера интерфейса ([02 · §10](02-design-tokens.md#10-размеры-интерфейса-масштаб-следует-за-рабочим-столом)): она сжимает только ячейки/плитки/строки контента, а масштаб интерфейса (по системному UI-кеглю: 100 % — компактная сетка, 125 % — широкий ×1.25) масштабирует весь UI.

## 9. Фильтр

- Инпут в тулбаре редактора; фильтрация по имени, case-insensitive, по всем группам/режимам.
- Пустой результат — «Нет совпадений» + «Попробуйте изменить запрос»; счётчики в тулбаре не меняются (это счётчики папки, не фильтра).
- `Esc` в поле — очистить; крестик — очистить; после ввода/очистки — «Сканирование…» → «Готово.» (~600 ms).
- Фильтр не влияет на дерево Places (там свой поиск).

## 10. Табы и навигация

- Табы: `.cache` (active), `Домашняя папка`, `Загрузки`; клик — переключение представления, пути, контента, выделения по `defaultSel`; active underline 3px; close 16px появляется на hover/active (в прототипе декоративный).
- Назад/вперёд/вверх: «вперёд» циклически переключает табы; «вверх» из `.cache`/`Загрузки` → `Домашняя папка`, из неё — подсказка «верхний уровень».
- Dropdown пути: 5 известных путей (`/home/frimm/.cache`, `/home/frimm`, `/home/frimm/Загрузки`, `/home`, `/`); пункт с checkmark — текущий.
- Переход по пути запускает «Сканирование…» → «Готово.».

## 11. Редактирование пути

1. Клик по карандашу (`#btnPathEdit`) → путь скрывается, появляется input с текущим путём, фокус + выделение всего текста (`select()`).
2. `Enter` — коммит: нормализация (удаление хвостовых `/`, пустое → `/`); поиск точного совпадения среди `VIEWS[].path`:
   - совпало — переключить представление (если другое) или обновить статус;
   - не совпало — вернуть прежний путь и показать `bandNote('Путь недоступен')`.
3. `Esc` / потеря фокуса — отмена, возврат к прежнему пути.
4. `#btnPathEdit`/`#pathAnchor`/`#pathInput` — взаимоисключающая видимость; dropdown во время редактирования закрыт.
5. Полный путь хранится только в тулбаре; в статус-баре его нет.

## 12. Выделение и инспектор

- Клик по hover-элементу (плитка/строка/ячейка) → `state.selected = item.n`; перерисовка полосы **без** сброса скролла (выделение обновляется точечно); инспектор перерисовывается.
- Инспектор показывает: тип (Папка/Файл), размер, изменён, создан, владелец/группа (frimm), права (`drwxr-xr-x`/`-rw-r--r--`), путь, «Доступ», «Содержимое» (127 папок / 19 файлов).
- Начальное выделение — `uv`.
- Кнопка «Открыть» — проскроллить выбранный объект в видимую область (и раскрыть свёрнутую группу в «Столбцах»); «Показать в папке» — переключить левую панель в «Файлы» и выделить родителя.
- Hover отдельный от selected; focus-visible — accent ring.

## 13. Статус-бар

- Состояние: `Сканирование…` (muted, класс `is-scanning`) и `Готово.` (secondary).
- Тайминги: при загрузке — `Сканирование…` на 900 ms → `Готово.`; при переключении таба/пути — 650 ms; при сортировке/режиме/группировке/видимости — 650; при фильтре — 600; при ручном обновлении — 600; кнопка/пункт сброса — 600–700.
- `role="status"`, `aria-live="polite"`; при повторном сканировании таймер перезапускается.
- Справа: свободное место и `sdc1` (имя устройства) — статичны для макета; в продукте — из реального тома.
- Слева нет пути, счётчиков, зума, режима; счётчики — в тулбаре редактора.

## 14. Панели, нижняя панель, окно

- Рейлы: клик — переключает панель (left/right), активная кнопка `is-active`; «скрыть панель» → ширина 0 (с переходом 120 ms); «показать» — обратно 280/300.
- Заголовок панели «Места» (chevron) сворачивает панель; действия: обновить (перерисовать дерево), «…» (развернуть/свернуть всё), скрыть.
- Правая панель «Сведения»: «…» → «Показать в дереве» / «Скрыть панель».
- Нижняя панель: вкладки «Операции»/«Журнал»; «—» сворачивает 180→40 (иконка меняется); «…» → «Очистить завершённые» (disabled при отсутствии); журнал пополняется строками синхронизации.
- Окно: свернуть → высота окна 40 (шапка), развернуть → масштаб под вьюпорт, закрыть → карточка «приложение закрыто» с кнопкой «Открыть Волну»; `fit()` пересчитывается на resize.
- Все кнопки окна имеют hover/active; close-hover красный (`#db5c5c`).

## 15. Клавиатура и доступность

| Клавиша | Действие |
|---|---|
| `Tab` / `Shift+Tab` | обход контролов; focus-visible — accent ring |
| `Escape` | закрыть поповер/меню, отменить редактирование пути, очистить фильтр (если фокус в поле) |
| `Enter` | подтвердить путь; активировать кнопку |
| `Home` / `End` | на слайдере масштаба — 0 / 100 |
| `Arrow` | стандартное поведение слайдера/radio (если реализовано нативными контролами) |

Требования: все иконочные кнопки — `title`/`aria-label`; табы — `role=tab`, `aria-selected`; радио/чекбоксы в «Вид» — `role=radio`/`checkbox` + `aria-checked`; триггеры — `aria-haspopup`, `aria-expanded`; статус — `role=status`.

## 17. Граничные случаи

| Случай | Поведение |
|---|---|
| Фильтр не дал результатов | empty state во всех режимах; счётчики не меняются |
| Выбран скрытый объект, скрытые выключили | selection → `defaultSel` |
| Сортировка по размеру, есть «—»/0 Б | `null`/«—» в конце при любом направлении |
| Сворачивание группы в «Столбцах» | только grouped columns; состояние групп сохраняется при переключениях |
| Смена режима при открытом «Вид» | поповер остаётся открыт, полоса перерисовывается |
| Редактирование пути + Esc/клик вне | отмена, прежний путь, dropdown закрыт |
| Неизвестный путь | `bandNote` «Путь недоступен», путь не меняется |
| Узкий вьюпорт | масштабирование окна (min 0.2), внутренние размеры не меняются |
| Нет завершённых операций | пункт «Очистить завершённые» disabled с пояснением |
| Скрытые файлы + режим «Подробности» | строки `.gitignore`/`.cache.lock` приглушены |
| Переименование в существующее имя | `bandNote` «Пресет с таким именем уже существует», редактирование продолжается |
| Удаление текущего пресета | fallback на «По умолчанию» и его применение |
| Удаление кастомного оверрайда встроенного | встроенный снова появляется в списке |
| Клик по действию пресета | не применяет пресет и не закрывает поповер/список |

## 18. Пресеты отображения

### 18.1 Модель

- Пресет = именованный снапшот настроек: `{viewMode, grouping, sort, sortDir, showHidden, compact, zoom}`.
- Встроенные (не удаляются, не перезаписываются напрямую):
  - «По умолчанию» — columns, by date, date↓, без скрытых, обычная, zoom 50 (100%);
  - «Плотный список» — details, by date, date↓, компактная, zoom 50;
  - «Крупные значки» — icons, by date, name↑, обычная, zoom 85;
  - «Без группировки» — columns, none, size↓, обычная, zoom 50.
- Пользовательские хранятся в `localStorage['volna.presets.v1']` (массив `{id,name,settings}`); перекрывают встроенный пресет с тем же именем. При недоступности storage — только в памяти.
- Выбор пресета (`#btnPresetSelect`) открывает инлайн-список (`#presetList`), текущий отмечен галочкой; клик — применить и закрыть список; Esc/клик вне — закрыть список (не закрывая поповер).

### 18.2 Применение пресета

1. Записать снапшот в `state` (все 7 полей), `state.presetId = id`, `presetDirty = false`.
2. Если скрытые выключены, а выбран скрытый объект — откат на `currentView().defaultSel`.
3. `#appWindow` — класс `is-compact` по значению пресета.
4. Перерисовать полосу (`renderBand()`), применить зум (`applyZoom()`), обновить инспектор (`renderDetails()`), синхронизировать контролы (`syncViewPopover()`), обновить label пресета.
5. Статус: `Сканирование…` → `Готово.` (~600 ms).
6. Поповер «Вид» остаётся открыт (кроме закрытия списка пресетов).

### 18.3 «Настроено вручную»

- Любое ручное изменение 7 полей (режим, группировка, ключ/направление сортировки, скрытые, compact, zoom) вызывает `markPresetManual()`: если текущий снапшот не совпадает с выбранным пресетом — `presetId = null`, label «Настроено вручную».
- Изменения, сделанные применением пресета, не помечают его изменённым.
- Пресет можно сохранить из ручного режима (диалог предложит «Мой вид»).

### 18.4 Диалог сохранения

| Шаг | Поведение |
|---|---|
| Открытие | клик по `#btnPresetSave`; список пресетов закрывается; input предзаполнен («<Имя> (копия)» или «Мой вид»), фокус + select; оверлей на всё окно |
| Имя | trim; пустое → кнопка «Сохранить» disabled; совпадение по имени (case-insensitive) → подсказка о перезаписи (warning) |
| Выбор существующего | клик по строке списка подставляет имя в input (перезапись) и фокусирует поле |
| Сохранение | валидное имя → снапшот текущих настроек; существующий пользовательский пресет перезаписывается, иначе создаётся новый (id `custom-<timestamp>`); сохраняется в localStorage; пресет становится выбранным; диалог закрывается; фокус — на `#btnPresetSave`; `bandNote('Пресет сохранён: <name>')`; поповер «Вид» остаётся открыт |
| Перезапись встроенного | пользовательский пресет с тем же именем создаётся/заменяется и визуально перекрывает встроенный (встроенный не мутируется) |
| Отмена | «Отмена», Esc, клик по оверлею — закрыть без изменений, вернуть фокус на кнопку сохранения |
| Клавиатура | Enter в input = сохранить; Esc = отмена; Tab — по контролам диалога |

### 18.5 Связь с остальным UI

- Выбор пресета не меняет данные/вкладку/выделение (кроме отката скрытого выделения), только представление.
- Ручные изменения сбрасывают привязку к пресету, но не удаляют и не сохраняют его.
- Удаление пресетов в текущей версии не предусмотрено (задел: контекстное меню в списке).
- При перезагрузке страницы подтягиваются только пользовательские пресеты; остальное состояние — дефолты.

### 18.6 Переименование пресета

- Доступно только для пользовательских пресетов (у встроенных действий нет).
- Кнопка «карандаш» в строке списка → строка переходит в режим редактирования: input 24px с текущим именем, автофокус и выделение; действия скрыты.
- `Enter` — подтвердить: trim; пустое имя → `bandNote('Имя пресета не может быть пустым')`, редактирование продолжается; имя, совпадающее с другим пресетом (case-insensitive, включая встроенные) → `bandNote('Пресет с таким именем уже существует')`, редактирование продолжается; то же имя — no-op/cancel.
- Валидное переименование: меняется только имя (id и снапшот настроек сохраняются), запись в localStorage, перерисовка списка; если переименован текущий пресет — обновляется подпись в поле выбора; `bandNote('Пресет переименован: <новое имя>')`; список/поповер остаются открыты.
- `Escape` или потеря фокуса — отмена без изменений; клик по input не применяет пресет.

### 18.7 Удаление пресета

- Доступно только для пользовательских пресетов.
- Кнопка «корзина» → диалог подтверждения «Удалить пресет?» с текстом «Пресет «<имя>» будет удалён. Это действие нельзя отменить.».
- «Отмена»/Esc/backdrop — без изменений (фокус по умолчанию на «Отмена»). «Удалить» — подтверждение.
- Подтверждение: удалить из `customPresets`, сохранить localStorage, перерисовать список. Если удалён текущий пресет — применить встроенный «По умолчанию» (id `default`); если удалён кастомный, перекрывавший встроенный, — встроенный снова виден. `bandNote('Пресет удалён: <имя>')`; список/поповер остаются открыты; фокус — на поле выбора пресета.
- Удаление не-текущего пресета сохраняет текущий выбор.
- Встроенные пресеты удалить нельзя (действий нет); удаление последнего кастомного просто оставляет список встроенных.
