# 08 · Критерии приёмки

Чек-листы для дизайн-ревью и для реализации. Пункт считается принятым только при визуальной проверке в браузере на 1440×900 (или скриншоте 1600×1000) и, где применимо, при ручном взаимодействии.

## 1. Визуальная система

- [ ] Используются ровно две основные поверхности (`#1e1f22`, `#2b2d30`); нет третьего серого фона.
- [ ] Границы — 1px; нет 2–3px рамок, кроме акцентного подчёркивания вкладки и прогресса.
- [ ] Внутри окна нет градиентов, теней, glass/glow; тени только у окна на сцене и у поповеров.
- [ ] Акцент `#3574f0` только как состояние (фокус, активный таб, radio/checkbox, прогресс), не как декор.
- [ ] Папки — синие контентные глифы; не путаются с акцентом.
- [ ] Заголовки — title case, без uppercase и letter-spacing (кроме 11px section title с .02em).
- [ ] Иконки одного семейства: contour 16/20px, stroke 1.25–1.5px, `currentColor`.
- [ ] Тени/радиусы соответствуют спеке (контролы 4, тайлы 6, поповеры/окно 8).
- [ ] Контрастность: основной текст ≥ 4.5:1, вторичный ≥ 3:1 на своих поверхностях.
- [ ] Нет «декоративных» анимаций: только color/background/border 120ms.

## 2. Компоновка

- [ ] Окно ровно 1440×900; вертикальный бюджет 40+1+40+1+608+1+180+1+28 = 900.
- [ ] Горизонтальный бюджет: рейлы 40/40, панели 280/300, редактор 780.
- [ ] Путь только в тулбаре; в статус-баре пути нет.
- [ ] «Вид» слева от пути и не смещается при переключении между `/home/frimm`, `/home/frimm/.cache`, `/home/frimm/Загрузки`.
- [ ] Статус-бар: слева только статус, справа `свободно 22,8 ГиБ · sdc1`.
- [ ] Никакого клиппинга/наложения текста; поповер «Вид» полностью помещается (max-height/internal scroll).
- [ ] Редактор: 32px тулбар + 576px полоса; прокрутка только внутри полосы.
- [ ] При уменьшении вьюпорта окно масштабируется целиком, внутренние размеры не «плывут».

## 3. Компоненты

- [ ] Тулбар: ☰, назад/вперёд/вверх (disabled у назад), «Вид», путь+карандаш, spacer, шестерёнка, контролы окна.
- [ ] В рейлах нет терминала и настроек; правый рейл — «Сведения»/«Предпросмотр».
- [ ] Header band: заголовки панелей + табы; активный таб с 3px accent underline; close 16px на hover/active.
- [ ] Дерево: нет дублей локаций, «Домашняя папка» один раз; секции «В сети», «Недавно изменённые», «Устройства» по одному разу.
- [ ] «Вид»: секции в порядке Режим → Группировка → Сортировка → Параметры → Масштаб; footer «Изменения применяются сразу».
- [ ] Radio/checkbox 14px, строки 26px, сегмент 24px, слайдер 96px/4px/10px.
- [ ] «Значки»: секции дат (заголовок 28 + count), сетка 150–178px, иконка 48–72, имя 2 строки.
- [ ] «Столбцы»: колонки по 236px (зум 200–280), 3-строчная ячейка 62px (54 в compact), иконка 48 (40).
- [ ] «Подробности»: sticky-шапка 28, группы 28, строки 24, колонки 1fr/96/168/76.
- [ ] Инспектор: карточка 64, метаданные, «Доступ», «Содержимое», кнопки 32px снизу.
- [ ] Нижняя панель: только «Операции»/«Журнал», строки 24px, прогресс 4px.
- [ ] Статус: `role=status`, `aria-live=polite`.

## 4. Взаимодействия

- [ ] «Вид» открывается по клику, закрывается по клику вне/Esc/повторному клику; `aria-expanded` синхронизирован.
- [ ] Смена режима мгновенно перерисовывает полосу, сохраняет фильтр/сортировку/группировку/зум/выделение.
- [ ] Группировка: grouped → заголовки/колонки; ungrouped → плоские списки/безголовые колонки.
- [ ] Сортировка по дате/размеру/имени + направление работает во всех режимах; «—»/0 Б в конце.
- [ ] Зум 0–100 меняет ширину колонок и иконки (48–72/40–56); Home/End; «Сбросить масштаб» → 50/100%.
- [ ] Скрытые файлы: добавляются `.gitignore` и `.cache.lock` (приглушены), снимаются обратно; выделение не «залипает».
- [ ] Плотная раскладка: колонки 54, плитки 132, «Подробности» 12px; выравнивание не ломается.
- [ ] Фильтр: live, case-insensitive, empty state «Нет совпадений» во всех режимах; `Esc`/крестик очищают.
- [ ] Табы: переключение меняет контент/путь/выделение; карандаш пути работает (Enter/Esc/blur, неверный путь — заметка).
- [ ] Клик по объекту обновляет «Сведения» без прыжка скролла; «Открыть» прокручивает к объекту.
- [ ] Рейлы/панели: переключение, скрытие (280/300→0), заголовки; нижняя панель сворачивается 180→40.
- [ ] Окно: свернуть/развернуть/закрыть и «Открыть Волну»; масштаб пересчитывается при resize.
- [ ] Статус: при загрузке «Сканирование…» → «Готово.» (~900ms), после действий — 600–700ms.
- [ ] Deep-links `#view`, `#icons`, `#details`, `#ungrouped`, `#icons-ungrouped` работают.
- [ ] Нет «мёртвых» кнопок: каждая интерактивная кнопка имеет hover/focus/active или осознанно disabled с пояснением.

## 5. Контент

- [ ] 5 групп дат: Сегодня (3), Вчера (6), Среда (2), Вторник (1), Неделю назад (2).
- [ ] Имена/размеры/даты соответствуют [`design/content-spec.md`](../content-spec.md) (starshp, uv, gh, mc, …).
- [ ] Счётчики «127 папок · 19 файлов (80,1 МиБ)»; свободно «22,8 ГиБ»; устройство `sdc1`.
- [ ] Инспектор для `uv`: 16,6 ГиБ, «Сегодня в 03:11», `/home/frimm/.cache/uv`, права `drwxr-xr-x`.
- [ ] Скрытые: `.gitignore` (184 Б), `.cache.lock` (0 Б) с корректными группами.
- [ ] Нет lorem ipsum, выдуманных имён/метрик; русские подписи и кавычки.
- [ ] Скрытые файлы/пустые состояния выглядят как данные, а не как заглушки.

## 6. Доступность

- [ ] Все иконочные кнопки имеют `title` и/или `aria-label`.
- [ ] Табы: `role=tab`, `aria-selected`; рейлы — кнопки с понятными названиями.
- [ ] «Вид»: `role=radio`/`checkbox` + `aria-checked`; триггер `aria-haspopup`, `aria-expanded`.
- [ ] Видимый `:focus-visible` на всех интерактивных элементах (1px accent).
- [ ] Статус — `role=status`, `aria-live=polite`; изменения озвучиваются.
- [ ] Управление с клавиатуры: Tab-порядок логичный, Esc закрывает поповеры/редактирование, Enter подтверждает путь.
- [ ] `prefers-reduced-motion`: анимации отключены.
- [ ] Цвет не единственный носитель смысла (selection — фон + контраст, статусы — текст).

## 7. Устойчивость

- [ ] Нет console errors/warnings при загрузке и переключениях.
- [ ] Нет внешних сетевых запросов; файл открывается офлайн.
- [ ] Нет дублирующихся id в DOM.
- [ ] Нет горизонтального скролла у страницы; переполнение только внутри областей.
- [ ] При быстрых повторных переключениях режимов/группировки нет «залипших» классов и пустых полос.
- [ ] Масштаб окна 0.2–1.0: контент не разъезжается.
- [ ] Файл < 130 KB, без зависимостей; перерисовка полосы не вызывает заметных лагов.

## 8. Матрица режимов

| Проверка | Значки | Столбцы | Подробности |
|---|---|---|---|
| Группировка по дате (заголовки + counts) | ✅ | ✅ | ✅ |
| Без группировки (плоский вид) | ✅ | ✅ (безголовые колонки) | ✅ |
| Фильтр + empty state | ✅ | ✅ | ✅ |
| Сортировка + направление | ✅ | ✅ | ✅ |
| Скрытые файлы | ✅ | ✅ | ✅ |
| Плотная раскладка | ✅ | ✅ | ✅ (шрифт 12) |
| Выделение → «Сведения» | ✅ | ✅ | ✅ |
| Масштаб влияет | ✅ (плитки) | ✅ (колонки) | — (24px стандарт) |
| Вертикальный скролл | ✅ | — (горизонтальный) | ✅ |
