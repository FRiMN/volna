# «Волна» — спецификация дизайна файлового менеджера

Implementation-grade спека для направления **C — Dolphin × JetBrains** (гибрид KDE Dolphin + JetBrains New UI), выбранного из трёх вариантов. Спека описывает финальный макет, токены, компоненты, поведение и критерии приёмки так, чтобы его можно было реализовать в реальном приложении без сверки с чатами и скриншотами.

**Версия:** 1.6 · 2026-11-17 (масштаб интерфейса следует за системным UI-кеглем; широкий/компактный — референсные точки)
**Канонический артефакт:** [`design/artifacts/variant-c.html`](../artifacts/variant-c.html) — самодостаточный HTML-макет (inline CSS/JS/SVG), широкий пресет 1800×1125 по умолчанию (`?size=compact` — 1440×900), русская локаль.
**Прочие варианты:** [`variant-a.html`](../artifacts/variant-a.html) — верный Dolphin (эталон референса), [`variant-b.html`](../artifacts/variant-b.html) — JetBrains Workbench (эталон панельной грамматики и светлой темы).
**Скриншоты:** [`design/screens/`](../screens/) — основной экран, «Вид», пресеты (список, действия, переименование, удаление, диалог сохранения), режимы «Значки»/«Подробности», без группировки, компактный пресет (`variant-c-compact.png`), коллаж `compare.png`.

## Коротко

- **Окно** 1440×900 на 100 %-десктопе (тулбар 40, рабочая область 608, нижняя панель 180, статус-бар 28) и 1800×1125 на 125 % (тулбар 50, хедер-бэнд 50, рабочая область 761, нижняя панель 225, статус-бар 35) — одна сетка, масштаб от системного UI-кегля.
- **Токены**: `#1e1f22`/`#2b2d30`/`#393b40`/`#3574f0`, Inter 14/13/12, JetBrains Mono для чисел; без градиентов/теней внутри окна.
- **Хром**: рейлы 40, левая панель 280, редактор 780, правая 300; табы 40 с 3px accent underline.
- **«Вид»** — единый поповер: пресеты отображения (с сохранением в диалоге), режимы «Значки/Столбцы/Подробности», группировка, сортировка, скрытые файлы, плотность, масштаб.
- **Размеры интерфейса** — одна компактная сетка (окно 1440×900, UI 100 %), которая масштабируется системным UI-кеглем (на 125 % — широкий пресет 1800×1125, ориентир — PyCharm на 125 %); в макете пресеты включаются `is-wide` / `?size=compact`. Ручной оверрайд в продукте появится в настройках.
- **Пресеты** — 4 встроенных + пользовательские (сохраняются в `localStorage`), диалог выбора/ввода имени и перезаписи, переименование и удаление из списка (встроенные неизменяемы).
- **Путь** — только в тулбаре, с кнопкой редактирования; статус-бар — только статус + `свободно 22,8 ГиБ · sdc1`.
- **Никаких дублей контролов и терминала**; все три режима — реальные.

## Быстрый просмотр

```bash
cd design/artifacts
python3 -m http.server 8080
# открыть http://localhost:8080/variant-c.html
# состояния: #view, #presets, #presets-save, #icons, #details, #ungrouped, #icons-ungrouped
```

Скриншоты и сравнение пересобираются скриптами [`design/tools/shot.sh`](../tools/shot.sh) и [`design/tools/build_compare.py`](../tools/build_compare.py).

## Границы прототипа

Это дизайн-макет, а не продукт: файловая система, операции и настройки эмулируются; окно живёт на «сцене» и масштабируется под вьюпорт; данные (`.cache`, 127 папок / 19 файлов, `sdc1`, 22,8 ГиБ) — демонстрационные и взяты из референса. Всё перечисленное — осознанные ограничения, а не недоделки; см. [06-implementation.md](06-implementation.md#ограничения-прототипа).
